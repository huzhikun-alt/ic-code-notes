# IC 代码笔记 · IC Code Notes

给 IC / 芯片设计代码做笔记的阅读工作台。单文件、零依赖、打开即用。

> 面向 Verilog/SystemVerilog 以及周边脚本（Perl/Python），但笔记模型与语言无关。

## 在线试用

部署在 GitHub Pages：**https://huzhikun-alt.github.io/ic-code-notes/**

本地打开：保持 `index.html`、`ui-refresh.css`、`ui-refresh.js` 在同一目录，再打开 `index.html`，或用任意静态服务器。

## 界面与批注模式

- 默认浅色，可切换深色；主题和批注模式独立保存。
- **行末批注（默认）**：卡片跟随代码末尾，没有批注的行保持紧凑。
- **右侧对齐**：保留固定右列和可拖动分隔条，多行批注仍下推后续代码。
- **纯代码**：暂时隐藏批注，不删除数据。
- 批注内 `Shift+Enter` 换行，`Enter` 完成编辑。
- 左侧以工程和文件为主，函数快捷入口默认折叠，完整函数库仍在顶部独立页面。

界面回归测试：安装 Python Playwright 后运行 `python verify-ui.py`（使用本机 Chrome）。

## 它解决什么

读 IC 代码时，笔记通常有两个落点，而大多数工具只做其中一个：

1. **贴在某一行代码上的理解** —— 「这个 `always_ff` 为什么这样打拍」
2. **跨项目复用的符号知识** —— 「`normalize` 这个函数是干什么的」

这个原型把两者分开：

- **代码行笔记**：挂在行上，卡片在代码右侧，卡片多高就把后面的代码推下去多少
- **函数库**：全局资产，按**语言**隔离，跨工程共享；选中函数名右键即可收录，之后在所有同类文件里悬停可看

## 功能

### 阅读与编辑
- 三语言语法高亮（Perl / Python / Verilog）
- **单击任意代码行直接输入**，Enter 换行并自动沿用缩进（行尾是 `{` 或 `:` 会多缩一级），Tab 插入缩进
- **粘贴一大段代码会自动按行拆开**，不会挤成一行
- 空行按 `Backspace` 删行，`Esc` 取消本次编辑
- **Ctrl+Z / Ctrl+Shift+Z 撤销 / 重做最近 60 步**（改行、加减行、粘贴、摘注释、增删笔记都算一步）
- **双击括号**高亮配对的另一只括号，并标出它圈住的行范围
- **拖动代码与笔记之间的竖线**调整两边宽度，宽度会记住
- 行号旁的笔记标记、右侧笔记卡片（自动保存、清空自动删除）
- 悬停函数名弹出描述卡片，含跨工程出现次数

### 粘贴代码 · 自动摘注释
AI 生成的代码通常带一堆注释。点左侧 `⇩`，整段粘进去，会：

- **自动识别语言**（看 `module` / `def` / `sub` 等特征），也可手动改
- 按该语言的注释语法拆解：Perl/Python 用 `#`，Verilog 用 `//` 和 `/* */`
- **连续的整行注释合并成一张卡片**，贴到它所注释的那行代码右边
- 行尾注释（`x = 1;  # 说明`）单独挂在该行
- 左边只留干净代码，注释行的空行会去掉
- shebang（`#!/usr/bin/env perl`）保留在代码里，不当注释摘走
- 文件名自动从 `module xxx` / `def xxx` / `sub xxx` 推断

摘出来的注释是**冷灰蓝卡片**，我自己的笔记是**暖黄卡片**——一眼能分清哪些是原作者写的、哪些是我写的。

已经存在的文件也可以补摘：文件头点 **「摘注释」**，会把当前文件里的注释整批搬到右侧，并把已有笔记按新行号重新挂好。

**注释识别是字符串感知的**：`"a#b"`、`'x#y'`、`$#array`、`"http://..."` 都不会被误判成注释。

### 笔记锚点（重点）
笔记**不存行号，存那一行的内容指纹**。所以：

- 你在笔记上方插入/删除代码，笔记自动跟着走，不会错位到别的行
- 代码被改得面目全非时，笔记按指纹在文件里找回来，标 `↻ 原第 N 行`，可一键「固定」
- 实在找不到（那行被删了），笔记**不会静默消失**，而是进底部的「未定位」区，可以重新选行绑定或删除
- 两条笔记抢到同一行时标 `⚠ 与其他笔记重叠`

### 文件 / 工程
- 多工程切换、新建 / 重命名 / 删除
- 新建 / 重命名 / 复制 / 删除文件（语言决定函数库匹配范围）
- 删除文件时行号锚点自动偏移（插入/删行会同步移动笔记位置）

### 函数库
- 右键选中函数名 → 加入函数库（支持签名、描述、标签）
- 按语言隔离：Perl / Python / Verilog 各自独立
- **同名多定义检测**：同一语言下出现多个定义时卡片标红并提示
- 导入 / 导出 JSON

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 编辑当前行 | 双击代码行 |
| 提交并新建下一行 | `Enter` |
| 取消编辑 | `Esc` |
| 删除空行 | 空行上按 `Backspace` |
| 完成笔记编辑 | `Ctrl + Enter` |
| 保存 | `Ctrl + S` |

## 数据

全部存在浏览器 `localStorage`，刷新不丢：

| Key | 内容 |
|---|---|
| `icn-lib` | 函数库 |
| `icn-notes` | 行内笔记 |
| `icn-proj` | 当前工程 |
| `icn-data` | 自定义工程/文件（一旦你新建过文件） |

右上角「重置数据」可清空回到初始示例。

## 已知限制

- **没有真实语言解析器**：语法高亮和符号识别基于词法切分，不是 AST
- **注释摘取是启发式的**：按注释符号切分，不处理字符串里的 `#`（例如 Python 的 `"a#b"` 会被误切）；Python docstring 不当注释
- **冲突检测依赖手工定义表**：`DEFS` 是在代码里手写的，真实产品应由 PPI / ast / Verible 产出
- **锚点用整行内容做指纹**：如果文件里有完全相同的多行（如连续空行），重定位可能落到最近的一行；指纹相同即视为同一行
- **单机存储**：换浏览器或清缓存就没了，需要靠导出/导入迁移
- 示例工程与笔记是演示数据，不代表真实代码风格
