# IC 代码笔记 · IC Code Notes

给 IC / 芯片设计代码做笔记的阅读工作台。单文件、零依赖、打开即用。

> 面向 Verilog/SystemVerilog 以及周边脚本（Perl/Python），但笔记模型与语言无关。

## 在线试用

部署在 GitHub Pages：**https://huzhikun-alt.github.io/ic-code-notes/**

本地打开：保持 `index.html`、`ui-refresh.css`、`ui-refresh.js` 在同一目录，再打开 `index.html`，或用任意静态服务器。

## 界面与批注模式

- **9 套配色**：纸感浅色、石墨深色、Gruvbox 深/浅、Nord、Solarized 深/浅、Tokyo Night、One Dark。
  Gruvbox 与 Nord 的色值取自各自的 colorscheme 源文件；其余为公开配色。全部通过 WCAG 对比度校验（正文 ≥ 7:1，次要文字 ≥ 4:1）。
- 主题与批注模式独立保存。
- **行末批注（默认）**：卡片紧跟在代码行末尾，与代码行垂直居中；没有批注的行保持紧凑。
- **右侧对齐**：固定右列 + 可拖动分隔条，多行批注仍下推后续代码。
- **纯代码**：暂时隐藏批注，不删除数据。
- 批注内 `Shift+Enter` 换行、`Enter` 完成编辑；没有手动换行、也没碰到右边界时不会折行。
- **手动敲的行末注释会自动转成右侧注释卡**（按语言分别识别 `#` 与 `//`），可在 `⋯` 菜单里关闭。
- 顶部只留一个 `⋯` 菜单：撤销 / 重做 / 摘注释 / 行末注释自动转卡 / 未定位的笔记 / 配色 / 快捷键 / 重置。
- 未定位的笔记收进弹窗，不再占据正文。
- 批注的删除、固定等操作在该卡片悬停时出现，不占版面。
- 悬停函数弹出的说明卡可直接编辑签名和描述，失焦即保存；点击页面其它位置会关闭它。

界面回归测试：安装 Python Playwright 后运行 `python verify-ui.py`、`python verify-editing.py`、`python verify-redesign.py`、`python verify-presets.py`、`python verify-contrast.py`（使用本机 Chrome）。

## 它解决什么

读 IC 代码时，笔记通常有两个落点，而大多数工具只做其中一个：

1. **贴在某一行代码上的理解** —— 「这个 `always_ff` 为什么这样打拍」
2. **跨项目复用的符号知识** —— 「`normalize` 这个函数是干什么的」

这个原型把两者分开：

- **代码行笔记**：挂在行上，卡片在代码右侧，卡片多高就把后面的代码推下去多少
- **函数库**：全局资产，按**语言**隔离，跨工程共享；选中函数名右键即可收录，之后在所有同类文件里悬停可看

## 功能

### 阅读与编辑
- 三语言语法高亮（Perl / Python / Verilog）
- **代码区是一个完整的文本编辑器**（单个 textarea + 高亮层 + 行号列），选择和输入都是浏览器原生行为：
  - 鼠标从任意一行拖到另一行，正向反向都能连续选多行
  - `Ctrl+C` 复制保留换行
  - 输入、删除、撤销、光标移动全部按标准文本框工作
- `Enter` 自动沿用缩进（行尾 `{` / `begin` / `:` 会多缩一级），`Tab` / `Shift+Tab` 缩进与反缩进
- **Ctrl+Z / Ctrl+Shift+Z 撤销 / 重做 60 步**（改代码、增删笔记、AI 写入都算一步）
- 笔记显示在代码右侧独立的一列，**每一行都有对应的笔记位置**

### 笔记系统
- 一条笔记 = `{ id, 正文, 锚点指纹, 来源(me/ai), 创建时间, 修改时间 }`
- **手动笔记和 AI 笔记是同一套组件**：同样的显示、选择、编辑、保存、删除
- 新建：双击笔记列空白处，或点顶部「笔记」按钮（在当前行创建）
- 编辑：直接点笔记正文，失焦自动保存
- 删除：清空正文后失焦，或点中笔记左侧色条后按 `Backspace`
- AI 写入时若该行已有笔记，会先给出「并存 / 替换 / 跳过」的选择，不会并排再堆一张卡

### 笔记锚点
笔记**不绑定行号，绑定那一行的内容指纹**：

- 在上方插入/删除代码，笔记跟着原代码走
- 代码被改写时按指纹在文件里找回来
- 锚在空行上的笔记保持原位（空行无法区分彼此）


### 粘贴代码 · 自动摘注释
AI 生成的代码通常带一堆注释。点左侧 `⇩`，整段粘进去，会：

- **自动识别语言**（看 `module` / `def` / `sub` 等特征），也可手动改
- 按该语言的注释语法拆解：Perl/Python 用 `#`，Verilog 用 `//` 和 `/* */`
- **连续的整行注释合并成一张卡片**，贴到它所注释的那行代码右边
- 行尾注释（`x = 1;  # 说明`）单独挂在该行
- 左边只留干净代码，注释行的空行会去掉
- shebang（`#!/usr/bin/env perl`）保留在代码里，不当注释摘走
- 文件名自动从 `module xxx` / `def xxx` / `sub xxx` 推断

摘出来的注释是**冷灰蓝卡片**，我自己的笔记是**暖黄卡片**——一眼能分清哪些是原作者写的、哪些是我写的。

已经存在的文件也可以补摘：文件头点 **「摘注释」**，会把当前文件里的注释整批搬到右侧，并把已有笔记按新行号重新挂好。

**注释识别是字符串感知的**：`"a#b"`、`'x#y'`、`$#array`、`"http://..."` 都不会被误判成注释。

### 笔记锚点（重点）

### 文件 / 工程
- 多工程切换、新建 / 重命名 / 删除
- 新建 / 重命名 / 复制 / 删除文件（语言决定函数库匹配范围）
- 删除文件时行号锚点自动偏移（插入/删行会同步移动笔记位置）

### 函数库
- 右键选中函数名 → 加入函数库（支持签名、描述、标签）
- 按语言隔离：Perl / Python / Verilog 各自独立
- **同名多定义检测**：同一语言下出现多个定义时卡片标红并提示
- 导入 / 导出 JSON

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 编辑当前行 | 双击代码行 |
| 光标在代码里移动 | 直接点击 / 方向键 |
| 换行并沿用缩进 | `Enter` |

## 数据

全部存在浏览器 `localStorage`，刷新不丢：

| Key | 内容 |
|---|---|
| `icn-lib` | 函数库 |
| `icn-notes` | 行内笔记 |
| `icn-proj` | 当前工程 |

## 已知限制

- **没有真实语言解析器**：语法高亮和符号识别基于词法切分，不是 AST
- **注释摘取是启发式的**：按注释符号切分，能正确处理 `"a#b"`、`$#array`、`http://`，但不处理 Python docstring
- **冲突检测依赖手工定义表**：`DEFS` 是手写表，真实产品应由 PPI / ast / Verible 产出
- **锚点用整行内容做指纹**：完全相同的多行（如连续空行）无法区分，空行上的笔记固定原位
- **笔记暂按纯文本编辑**：支持多段与长文本，但未渲染 Markdown / 代码块
- **函数悬停卡片已移除**：代码层是透明 textarea，无法做逐 token 悬停；改为「光标所在函数」提示条
- **单机存储**：换浏览器或清缓存就没了，需要靠导出/导入迁移
