# IC 代码笔记 · IC Code Notes

给 IC / 芯片设计代码做笔记的阅读工作台。单文件、零依赖、打开即用。

> 面向 Verilog/SystemVerilog 以及周边脚本（Perl/Python），但笔记模型与语言无关。

## 在线试用

部署在 GitHub Pages：**https://huzhikun-alt.github.io/ic-code-notes/**

本地打开：直接双击 `index.html`，或用任意静态服务器。

## 它解决什么

读 IC 代码时，笔记通常有两个落点，而大多数工具只做其中一个：

1. **贴在某一行代码上的理解** —— 「这个 `always_ff` 为什么这样打拍」
2. **跨项目复用的符号知识** —— 「`normalize` 这个函数是干什么的」

这个原型把两者分开：

- **代码行笔记**：挂在行上，卡片在代码右侧，卡片多高就把后面的代码推下去多少
- **函数库**：全局资产，按**语言**隔离，跨工程共享；选中函数名右键即可收录，之后在所有同类文件里悬停可看

## 功能

### 阅读
- 三语言语法高亮（Perl / Python / Verilog）
- 双击代码行直接编辑；`Enter` 换行提交、`Esc` 取消、空行 `Backspace` 删行
- 行号旁的笔记标记、右侧笔记卡片（自动保存、清空自动删除）
- 悬停函数名弹出描述卡片，含跨工程出现次数

### 笔记锚点（重点）
笔记**不存行号，存那一行的内容指纹**。所以：

- 你在笔记上方插入/删除代码，笔记自动跟着走，不会错位到别的行
- 代码被改得面目全非时，笔记按指纹在文件里找回来，标 `↻ 原第 N 行`，可一键「固定」
- 实在找不到（那行被删了），笔记**不会静默消失**，而是进底部的「未定位」区，可以重新选行绑定或删除
- 两条笔记抢到同一行时标 `⚠ 与其他笔记重叠`

### 文件 / 工程
- 多工程切换、新建 / 重命名 / 删除
- 新建 / 重命名 / 复制 / 删除文件（语言决定函数库匹配范围）
- 删除文件时行号锚点自动偏移（插入/删行会同步移动笔记位置）

### 函数库
- 右键选中函数名 → 加入函数库（支持签名、描述、标签）
- 按语言隔离：Perl / Python / Verilog 各自独立
- **同名多定义检测**：同一语言下出现多个定义时卡片标红并提示
- 导入 / 导出 JSON

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 编辑当前行 | 双击代码行 |
| 提交并新建下一行 | `Enter` |
| 取消编辑 | `Esc` |
| 删除空行 | 空行上按 `Backspace` |
| 完成笔记编辑 | `Ctrl + Enter` |
| 保存 | `Ctrl + S` |

## 数据

全部存在浏览器 `localStorage`，刷新不丢：

| Key | 内容 |
|---|---|
| `icn-lib` | 函数库 |
| `icn-notes` | 行内笔记 |
| `icn-proj` | 当前工程 |
| `icn-data` | 自定义工程/文件（一旦你新建过文件） |

右上角「重置数据」可清空回到初始示例。

## 已知限制

- **没有真实语言解析器**：语法高亮和符号识别基于词法切分，不是 AST
- **冲突检测依赖手工定义表**：`DEFS` 是在代码里手写的，真实产品应由 PPI / ast / Verible 产出
- **锚点用整行内容做指纹**：如果文件里有完全相同的多行（如连续空行），重定位可能落到最近的一行；指纹相同即视为同一行
- **单机存储**：换浏览器或清缓存就没了，需要靠导出/导入迁移
- 示例工程与笔记是演示数据，不代表真实代码风格

## 后续方向

- 接入真实解析器（Perl → PPI，Python → ast，Verilog → Verible）
- 指纹升级为「声明 + 上下文多行」，减少重复行歧义
- 笔记全文搜索
- 多文件工程导入
