# ic-code-notes：现状体检与修复计划（2026-11-13）

## 一、已确认的根因（不是猜测，都有实测数据）

### 1. 函数库卡片悬停变黑
- 浅色主题下卡片底色来自 `ui-refresh.css:310` → `var(--surface)` = `#ffffff`
- 但 `index.html:307` 写着 `.fcard:hover{background:#16202b}` —— **写死的深色**
- 实测：浅色主题悬停背景 `rgb(22,32,43)`（= #16202b），即"整张卡片变黑"
- 修复：改成 `background:var(--surface-soft)`，跟随主题（实测 `rgb(243,245,248)`）

### 2. 卡片右上"编辑/删除"变成白色竖条
- 卡片操作区 HTML 用的是 `class="ed"`（`index.html:2438`）
- 而 `ed.css:5` 定义 `.ed{display:flex;height:100%;background:var(--paper)}` —— 这是**编辑器容器**
- 类名撞车 → 操作区拿到 `height:100%` 与白底
- 实测：按钮被撑成 **19×140px** 的竖条，白底盖住卡片内容
- 修复：类名改为 `.fact`（`index.html` + `ui-refresh.css`），并显式 `align-items:flex-start; height:auto; background:none`
- 修复后实测：操作区 61×14，两个按钮各 27×14

